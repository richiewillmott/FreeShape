# FreeShape 2.4.0

A much fuller sketcher, Onshape's selection tools and keyboard shortcuts, an S menu of your own tools, direction
arrows that work like Onshape's, resizable planes — and Export as Python script, which writes a whole project as a
script that builds it again.

## Highlights

**A fuller sketcher** — the tools that were missing next to Onshape's:
- **Polygons** with any number of sides, **inscribed** (corners on a circle) or **circumscribed** (sides touching a
  circle, so its diameter is the size across flats — a nut pocket in two clicks and a number).
- **Midpoint line**, **aligned 3-point rectangle** at any angle, **tangent arc**, **elliptical arc**, **conic**
  (rho; double-click to change it) and a **control-point (Bézier-style) spline** with its control polygon.
- **Sketch chamfer**, **split**, **extend**, **transform / copy** (move and turn selected geometry, or a copy).
- **Intersect**: where part faces cross the sketch plane comes in as fixed construction geometry.
- **Insert DXF** (in the file's units; polylines, arcs, ellipses, splines, blocks; ends joined so outlines make
  areas) and **Insert image** to trace over, sized by dimensioning its corners.
- The sketch toolbar is grouped like other CAD programs, and **Extrude ▾ / Revolve / Sweep** on it finish the sketch
  and start the feature with its areas picked.

**Selecting like Onshape**
- **Planes come last**: a face, sketch or edge under the mouse wins over a plane running through it — no more getting
  Front or Right when you click a part centred on the origin.
- **Tab** steps through everything under the mouse — the face you see, the one behind it, edges, sketch geometry,
  planes — drawn through the model if it's hidden; a click selects the one shown. **`** (back quote) or right-click
  → **Select other…** lists it all.
- **Right-click selection tools**: tangent-connected faces or edges, adjacent faces, an edge's loop, a face's edges,
  and **faces or edges of the same size** (every M6 hole at once).

**Your tools at the mouse: the S menu** — press **S** over the model for a grid of your favourite tools. There's one
for sketches, Part Studios, assemblies and drawings, and *Customize…* fills each from every tool on that toolbar,
plugins included, in the order you like.

**Onshape's keyboard shortcuts** — P planes, Shift+P all construction geometry, Shift+H sketches, Y / Shift+Y hide /
show parts, Shift+I isolate, Shift+X section, Shift+V named views, Shift+R high quality, Z zoom out, W zoom window,
Shift / Ctrl+arrow turn 90° / 5°, Shift+N rename, Shift+Enter accept and start another, double-click the wheel to
fit. In sketches: M trim, X extend, B parallel, Shift+L perpendicular, Shift+O concentric, Shift+M midpoint,
Shift+Q symmetric, Shift+J fix, Shift+A tangent arc, Shift+F fillet, Shift+S point. **?** opens the full list — now
a table you can search.

**Direction arrows** — **Up to next / face / part / vertex** turn the Extrude or Revolve towards their target by
themselves (the second end too, which Onshape doesn't). **Click the arrow** in the view to flip the direction;
Revolve has an arrow now as well. In the dialogs the *Opposite direction* tick box is a clear arrow button.

**Separate** — a new option on Extrude, Revolve and Sweep (off by default, with New): areas that touch in the sketch
become **one part each** instead of one fused part. A 25 × 25 square cut into four by a cross, extruded 25, gives four
12.5 × 12.5 × 25 parts — as SALOME does, and what Onshape needs a custom feature for. Tick *Colour each part
differently* to give each its own colour.

**Resize planes** — select a plane (or several) and drag the dots at its corners. The size is kept in the file and
undoable; right-click → *Reset plane size*.

**Export as Python script** — Document → *Export as Python script…* writes the tab you're on and the tabs linked to it
(the Part Studios an assembly uses, the drawings of them) as one Python script in three parts — CAD model,
assembly, drawing — with your typed variables first as plain values: change `wall = 3` to `wall = 4`, run it again,
get the thicker version. Sketches are written one point, curve and dimension per line, and every face or edge a
feature uses is labelled in plain English. Document → *Run Python script…* opens what a script builds as new tabs;
`python my_model.py` saves the files.

**Fixed**
- With PySide6 6.11, submenus (the view cube's render and edge options, Open recent, Plugins …) could come up empty.
- A resized plane picked in a feature dialog was outlined at its default size.
- The Windows exe's Properties showed version 2.1.0.

Full details: [CHANGES.md](https://github.com/richiewillmott/FreeShape/blob/master/CHANGES.md).

## Download

- **Windows:** `FreeShape-Setup-2.4.0.exe` — installs over 2.3 (or the portable zip). SmartScreen may warn because
  the installer isn't code-signed yet: **More info → Run anyway**.
- **Mac (Apple Silicon):** `FreeShape-2.4.0-mac-arm64.dmg` — drag into Applications; the first time,
  right-click → **Open** → **Open**.
- **Linux:** `FreeShape-2.4.0-x86_64.AppImage` — `chmod +x` it and run it.

## Upgrading from 2.3

Install over it; your files open as before. Two keys changed in sketches: the **hexagon** is now **Shift+X** (X is
Extend, as in Onshape), and **S** opens the S menu (**Esc** picks Select). Files saved with resized planes open in
2.3 too, with the planes at their default size.
