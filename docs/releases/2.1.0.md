# FreeShape 2.1.0

Feature options brought up to Onshape's, a hexagon sketch tool, and big speed-ups for large models — especially
ones with imported STEP files.

## Highlights

**Feature options, built once and shared** ([#27](https://github.com/richiewillmott/FreeShape/issues/27))
Options that several features have are now written once and reused, so they behave the same everywhere.
[FEATURE_PARITY.md](https://github.com/richiewillmott/FreeShape/blob/master/FEATURE_PARITY.md) tracks every
feature's options against Onshape — now **95%** of the listed options, with 10 of 14 features complete.

- **Solid / Surface / Thin** for Extrude, Revolve, Sweep and Loft — surfaces from sketch curves, edges or
  outlines; thin walls either side, both, or two different thicknesses.
- **Extrude** — draft on either end; a second end with any end type; Up to ends for surfaces.
- **Revolve** — two directions. **Sweep** — profile control (keep orientation, lock to a direction or faces,
  follow a guide curve). **Loft** — curves as profiles, loft along a path.
- **Chamfer** — two distances, or distance and angle. **Fillet** — variable radius.
- **Hole** — up to next, up to a face, plane or vertex.
- **Patterns and Mirror** — of **faces** (repeat a boss or pocket, even on imported parts), a second direction
  for linear patterns, and Remove / Intersect.
- **Merge scope** — choose which parts Add / Remove / Intersect act on.

**Hexagon sketch tool** (`X`) — centre then corner; stays regular, snaps flat-top or point-top, and you size it
across flats.

**Much faster with big models**
- Imported STEP files are now stored as exact geometry: a 600-part model loads in **0.4 s instead of 14.5 s**,
  and its file shrank from **65 MB to 12.5 MB**.
- STEP files you've opened are cached, so big models open quickly the second time, even after a restart.
- No more "Not responding" after a big import: the 3D view is prepared in the background.
- Parts derived from another Part Studio don't reload the whole source when it hasn't changed.
- Modelled threads build several times faster.
- Sketching is much smoother on detailed parts.
- The progress bar moves feature by feature while a model rebuilds.

Full details: [CHANGES.md](https://github.com/richiewillmott/FreeShape/blob/master/CHANGES.md).

## Download

- **Windows:** `FreeShape-Setup-2.1.0.exe` — installs over 2.0. SmartScreen may warn because the installer
  isn't code-signed yet: **More info → Run anyway**.
- **Mac (Apple Silicon):** `FreeShape-2.1.0-mac-arm64.dmg` — drag into Applications; the first time,
  right-click → **Open** → **Open**.
- **Linux:** `FreeShape-2.1.0-x86_64.AppImage` — `chmod +x` it and run it.

## Upgrading from 2.0

- Everything made in 2.0 opens and rebuilds the same. New options default to the old behaviour.
- Files with an imported STEP convert to the new, smaller form the next time you save them (about a second).
  **Once saved in 2.1, FreeShape 2.0 can't rebuild that import** — keep a copy from 2.0 if you might need to go
  back.
- The first time you open a big model, its 3D view is prepared and cached; later opens are quick.

## Not yet

Conic fillets, loft guide curves and start / end tangency, and parting-line draft are still to do; sweep takes
one guide curve. See FEATURE_PARITY.md.
