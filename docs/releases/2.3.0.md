# FreeShape 2.3.0

Sub-assemblies, inch units, an Onshape-style toolbar, one Variable feature with units (and text), five new
plugins, STL resolution and your own icons — plus fixes for chamfers next to fillets and for small screens.

## Highlights

**Sub-assemblies** — insert an assembly into another. Open assemblies are listed in the Insert panel, and *From
file…* takes a `.fasm`. A sub-assembly comes in laid out as it is in its own tab and moves as **one rigid group**:
drag, move or turn any of its parts and the rest follow; fix, hide or delete it as a whole. **Mate to any of its
parts.** It stays linked — add, remove or move parts in its own tab and the assembly follows — and its parts are
saved in the file, so it opens even without the sub-assembly's file. Sub-assemblies can contain sub-assemblies.

**Inches (and other units)** — each Part Studio and Assembly has its own length unit (mm, cm, m, in, ft), set
from **Units ▾** at the bottom right, along with the default for new documents. Feature boxes, sketch dimensions,
measurements and the scale bar all follow it, and a bare number you type is in it. The model is still built in
millimetres, so switching never changes the part. (Drawings stay in millimetres for now.)

**Toolbars organised like Onshape's** — **Sketch** comes first with its name, then the features in Onshape's
order, with related tools under a **▾** (patterns, thicken / enclose, hole / thread, direct edits, sheet metal …).
The sketch toolbar groups variants too (rectangle / centre rectangle / hexagon …) and remembers the last one used.
The origin and planes sit in a foldable **Default geometry** group.

**One Variable feature, with units** (issue #31) — *Variable* and *Measure value* are now one **Variable**
feature: Length, Angle, Number, Any expression, or measured from the model. Lengths and angles have a unit (`1` in
*m* is 1000 mm). **Units are checked**: an angle used as a depth, or an area as a length, is an error that says so
instead of a silent wrong number, and a number box that can't be used keeps your text and says why.

**Text variables** — *Any expression* holds text too (`"Rev B"`, `"PN-" + #part`), and **sketch text can come
from variables**: tick *From variables* in the Text dialog. Part numbers and revisions can follow configurations.

**New plugins** (Document ▸ Plugins ▸ Manage plugins… ▸ *Add the examples*):
- **Gridfinity bin / baseplate** — grid size, height, dividers, stacking lip, magnet holes.
- **Timing pulley** — GT2 2 / 3 mm and HTD 3M / 5M from the number of teeth, with flanges, hub, bore and grub screw.
- **Lighten** — triangle, hexagon or circle pockets in flat faces, with set rib width and a solid border.
- **Laser-cut box** — finger-jointed panels from the size and sheet thickness, with kerf compensation, laid flat
  and exported to DXF.
- **Batch export** — every part to its own STL / STEP file, named after the part.

**STL resolution** — Coarse, Medium, Fine or Custom (deviation and angle) when exporting STL; remembered.

**Your own icons** (issue #30) — View ▸ Icons: an `.svg` / `.png` named like a tool in your icons folder replaces
the built-in icon. *Save the built-in icons there* gives you every icon, correctly named, to start from.

**Fixed**
- Chamfering a straight edge that runs into filleted edges (a box with a rounded top, say) failed with "too large"
  even for small sizes; it now works, carrying the bevel through the rounded corner as Onshape does.
- On a 1920-pixel (or smaller) screen the window was wider than the screen and cut off the view cube. The toolbars
  now fit (and scroll sideways if they don't), and FreeShape opens at a size that fits.
- Hovering the origin or a default plane in the feature list highlights it in the 3D view.

Full details: [CHANGES.md](https://github.com/richiewillmott/FreeShape/blob/master/CHANGES.md).

## Download

- **Windows:** `FreeShape-Setup-2.3.0.exe` — installs over 2.2 (or the portable zip). SmartScreen may warn
  because the installer isn't code-signed yet: **More info → Run anyway**.
- **Mac (Apple Silicon):** `FreeShape-2.3.0-mac-arm64.dmg` — drag into Applications; the first time,
  right-click → **Open** → **Open**.
- **Linux:** `FreeShape-2.3.0-x86_64.AppImage` — `chmod +x` it and run it.

## Upgrading from 2.2

- Everything made in 2.2 opens and rebuilds the same. Old Variable and Measure value features keep working.
- Because units are now checked, a model that (by mistake) used an angle as a length or similar will show that
  feature in red with the reason, where 2.2 quietly used the number. Fix the value and it rebuilds.
- Files that use sub-assemblies, text variables or the new plugins won't fully open in 2.2 — keep a copy if you
  might need to go back.

## Not yet

Flexible sub-assemblies (moving parts inside a sub-assembly from the top assembly), mate limits, angle dimensions
in drawings, and STEP export that keeps a compound's shared faces.
