# FreeShape 2.5.0

Variables made on the fly, a Variables table, copy and paste for features, Transform with all of Onshape's types,
mate connectors in Part Studios, Curve and Point patterns, a Normal sketch constraint, the view facing a sketch when
you open it to edit, and a drag arrow for an Extrude's second end.

## Highlights

**Create a variable as you type it** — type a `#name` that doesn't exist yet in a feature's value box (`#depth` in
an Extrude's depth, say) and FreeShape offers **Create #depth = 25 mm**, using the value the box had. Click it or
press Enter: a Variable is added **just before that feature** — even a feature far up the list, so it's defined in
time — and the box uses it. A depth makes a Length (in the document's unit), an angle an Angle, a count a Number, so
the unit check is happy straight away. Sketch dimension boxes offer it too, with the variable placed before the
sketch. Change its value later in the feature list and everything using it follows.

**Type `#` for a list of your variables** — with their values, in feature boxes, Variable values and sketch
dimension boxes, and part-way through an expression (`#wall * 2 + #g` offers `#gap`). Pick one with the mouse or the
arrow keys and Enter.

**Variables table** — Variable ▾ → *Variables table* lists every variable in the Part Studio with its value, kind,
what it's set to and which features use it. Change a value or a name right in the table: a new name follows the
variable into every feature, sketch dimension and configuration that uses it. *+ New variable* adds one, and the
window stays open while you work.

**Copy and paste features** — select features in the feature list, `Ctrl+C`, then `Ctrl+V` pastes copies at the
rollback bar, in this Part Studio or another (even in another FreeShape window); right-click → *Paste after this*
puts them after a feature. Features copied together stay linked — a pasted extrude uses the pasted sketch — and one
Undo takes the paste back.

**The view faces a sketch when you edit it** — *Orient normal to sketch on edit* (the view options under the view
cube) now turns the view to face an existing sketch when you open it to edit, as in Onshape, not only a new one.
Switching the option off while sketching goes back to the view you had; switching it on faces the sketch straight
away. It's remembered between sessions.

**Drag the second end of an Extrude** — tick *Second end position* with a Blind second end and a second arrow
appears, pointing the other way to the first: drag it to set the Second depth, as you drag the first arrow for the
Depth. Flip the first end and the second turns round with it.

**Transform, the Onshape way** — the Move feature is now **Transform**, with Onshape's types: *Translate by line*
(moves by the line's own length and direction), *by distance*, *by XYZ*, *Transform by mate connectors*, *Rotate*,
*Copy in place* and *Scale* — plus *Translate from point to point*. Files from 2.4 open as "by XYZ", unchanged.

**Mate connectors in Part Studios** — Transform ▾ → *Mate connector* puts a frame (origin and X / Y / Z) on a face,
edge or vertex. The face's possible points show as crosses — its middle, corners, edge middles and round-edge
centres; on a round face, its axis at the middle or either end. **Press Shift** (or click a cross) to move to the
next one without picking the face again, as Onshape does. Flip it, turn it about Z, nudge it along its axes. Then
*Transform by mate connectors* puts one onto another — a part's bottom face onto another's top, centred.

**Curve and Point patterns** — *Curve pattern* copies parts, features or faces along a path (sketch curves or
edges): spread along it or a set distance apart, turning with it or keeping their orientation. *Point pattern*
puts a copy at each vertex or sketch point you pick. Both are in the pattern button's menu.

**Normal constraint** — a line at right angles to a circle, arc or ellipse where they meet. Pick a line and a curve
and click **Perpendicular** (`Shift+L`).

**Up to a vertex at both ends** — the Onshape trick works: the first end up to a vertex, the second end up to the
same vertex stopping short by X gives a part X thick that ends at the vertex.

**One polygon tool** — the separate Hexagon tool duplicated Inscribed polygon (which starts at 6 sides and snaps
level), so it's gone from the toolbar; `Shift+X` starts the polygon.

## Sturdier models

This release also went through a full QA pass. These fixes are the ones you might notice:

- **Features stay on the right part.** Suppressing or deleting a feature that makes parts no longer renumbers
  the parts made after it, so a fillet, chamfer, name or colour on a later part stays on that part — it could
  quietly move to another body.
- **A lost edge or face is reported, not swapped.** When the edge or face a feature uses disappears upstream (its
  pocket suppressed or deleted, or the feature dragged above it), the feature now says *Missing edge reference*
  instead of rounding some other edge that looked similar. An inside corner is never taken for an outside one, nor
  a pocket's floor for the top face. Ordinary dimension changes still follow the edge, as before.
- **A sturdier sketch solver.**
  - Constraints that repeat what others already say (a parallel added to a 3-point rectangle, say) no longer
    freeze the sketch.
  - A circle can't be solved to a negative radius, or shrunk to nothing and silently dropped from the profile.
  - Big changes to sketches with parallel and perpendicular lines now solve where they used to give up.
  - A red constraint (one that can't be met) no longer stops you dragging or dimensioning the rest of the sketch,
    and its own geometry stays put.
- **Variables that don't fit are reported.** A variable value a sketch can't satisfy now shows as an error on the
  sketch, rather than building from half-solved geometry.
- **Expressions in every value box.** Second-direction counts and spacings, second radius and distance, draft
  angles, helix turns, height and start angle, and Transform's scale all take `#variables` and expressions now
  (some gave an error before).
- **DXF dimensions on detail views are right.** A view with its own scale (a detail view, or a view given a scale)
  exported its dimensions wrong: a 2:1 view's 60 mm read 120. *Full size* DXFs now draw those views at true size
  too.
- **Sheet metal follows Transform.** A sheet metal part moved or turned with Transform keeps its flanges, hems and
  flat pattern in step (a flange used to be built where the part had been). A copy is sheet metal too; a scaled
  part becomes a plain part.
- **Saving is safe.** A save that goes wrong part-way no longer leaves an empty file: the file is written alongside
  and swapped in.
- **A failed feature changes nothing.** One that fails part-way no longer leaves half its result in the model.
- **Small things.** `1e999` and other infinite numbers are refused instead of making a broken part. A circular
  pattern with a count of 0 explains itself. Names with line breaks can no longer break out of comments in an
  exported Python script.

## Fixes

- **Unticking Second end position** no longer leaves its picked vertex highlighted in the view.
- **`P` and the planes' eyes agree.** P hid the default planes, but the feature list still showed them as
  shown, and while one had them off the other did nothing. They're one switch now, saved with the Part Studio.

- **Messages no longer hide behind the splash screen.** A message shown while FreeShape starts — a file that needs
  a rebuild, a recovered autosave, an error — could sit underneath the splash, which stays on top, leaving nothing
  you could click. The splash now closes the moment a message opens.
- **The merge scope no longer covers your model.** With Add / Remove / Intersect, the part FreeShape puts in the
  Merge scope was highlighted the whole time — a whole STEP import turned yellow and hid the preview. It now lights
  up only while you click into the Merge scope box, as in Onshape.
- **Opening a sketch straight after a tab opened** could snap the view back to isometric instead of turning to face
  the sketch.

Full details: [CHANGES.md](https://github.com/richiewillmott/FreeShape/blob/master/CHANGES.md).

## Download

- **Windows:** `FreeShape-Setup-2.5.0.exe` — installs over 2.4 (or the portable zip). SmartScreen may warn because
  the installer isn't code-signed yet: **More info → Run anyway**.
- **Mac (Apple Silicon):** `FreeShape-2.5.0-mac-arm64.dmg` — drag into Applications; the first time,
  right-click → **Open** → **Open**.
- **Linux:** `FreeShape-2.5.0-x86_64.AppImage` — `chmod +x` it and run it.

## Upgrading from 2.4

Install over it, and your files open as before. **2.5.0 saves Part Studios in a new file format.** Parts are now
numbered within the feature that makes them (that's what keeps features on the right part). Older files are
converted by themselves when they open. Assemblies, drawings, derived parts, saved versions and exported scripts
that refer to their parts still find them.

- **Older versions:** once you've saved a Part Studio in 2.5.0, don't edit it in an older FreeShape. It can't read
  the new part numbers. Keep a copy of the old file if you need to go back.
- **The first open is slower.** A file from 2.4 or earlier rebuilds one extra time when it opens, until you save
  it.
- **Existing references:** edges and faces picked in earlier versions don't yet carry the information that
  detects a lost reference. Re-pick them if you want that check for an older model.

If you'd rather an edited sketch kept your view, switch *Orient normal to sketch on edit* off under the view
cube.
